# diginixit-saas-platform

A modern, serverless SaaS web application engineered for digital web engineering, design, and software consulting agencies. Features dedicated client management dashboards, interactive project estimation tools, and administrative consoles.

## Architecture and Stack

* **Frontend**: HTML5, Vanilla JavaScript, Modular CSS3
* **Backend**: Serverless architecture, Cloudflare Workers API endpoints
* **Data Layer**: Supabase PostgreSQL database
* **Hosting**: Netlify Edge Hosting

## Key Features

* **Client Dashboard**: Project milestone tracking, invoice inspection, and deliverable review.
* **Service Estimator**: Interactive scope estimator calculating project complexity and timelines.
* **Admin Console**: Centralized management of client accounts, service tiers, and subscriptions.
* **Lightweight Footprint**: Optimized asset payloads delivering rapid load times.

## Getting Started

### Installation
```bash
git clone https://github.com/itsgoharrehman/diginixit-saas-platform.git
cd diginixit-saas-platform
```

### Running Locally
```bash
npx serve .
```
